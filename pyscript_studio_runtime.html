Arquitectura & Guía de Instalación Offline

¿Qué es PyScript y cómo funciona?

PyScript es un lenguaje híbrido executable en el navegador que intercala bloques de Python real (mediante Pyodide CPython WebAssembly) y JavaScript nativo. Ejecuta los bloques secuencialmente y mantiene un puente bidireccional sincronizado de datos y funciones.

// Sintaxis Soportada:
<python> x = 100 </python>
<javascript> console.log(x); </javascript>
@import "modulo.pyscript"
@shared player_score, lives

🚀 Ejecución con Servidor Local (HTTP Server)

Por políticas de seguridad de los navegadores (CORS / WebAssembly), algunos navegadores restringen cargar módulos WASM directamente desde el protocolo file://.

Para ejecutar de manera óptima en tu máquina local:

python -m http.server 8000

Luego navega a http://localhost:8000 en tu navegador.

📦 Instalación de Pyodide 100% Offline (Sin Internet)

Para no depender de CDN en entornos de producción offline:

  1. Descarga la versión de Pyodide desde npm install pyodide o descarga el tarball oficial de pyodide-v0.26.4.tar.gz.
  2. Coloca la carpeta extraída dentro del directorio de tu proyecto (ej: /pyodide/).
  3. Sustituye la etiqueta script de importación por:
    <script src="./pyodide/pyodide.js"></script>
  4. En el runtime JS, inicializa especificando la ruta local:
    loadPyodide({ indexURL: "./pyodide/" })
